---
name: architecture-patterns
description: loop for analyzing codebase for architectural patterns
---

Analyze the codebase through the lenses of design patterns, architectural style, and system structure.
Evaluate appropriate use of patterns and implementation quality, and assess whether the architecture
meets the needs of the target goal and scope of the project. Look for signs of over-engineering, and pattern
misuse in the design. For any issues, create a kata issue using `kata create` if an issue does
not already exist. Read the open issues first so you file additions, not duplicates.

Title issues with an `architecture:` prefix so the pass that found them stays identifiable later.

If nothing is found, say "No architectural issues found in this project"
