---
name: clean-code
description: loop for assessing clean code violations in a project
---

Analyze the codebase for Clean Code violations, keeping in mind the scope of the project. For any
violation found, create a kata issue using `kata create` if an issue does not already exist for it.
Read the open issues first so you file additions, not duplicates.

Title issues with a `clean-code:` prefix so the pass that found them stays identifiable later.

If nothing is found, say "No clean code violations found in this project"
